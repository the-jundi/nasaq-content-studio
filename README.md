# نَسَق · Nasaq Content Studio

**An agent skill that runs a brand's social content end to end, Arabic-first.** It imposes no house style: it finds the brand's identity files on your machine, interviews you, researches fresh inspiration on every run, explores two or three content styles, and adopts the one your audience rewards. It plans a week or a month, designs and checks the posts, asks before using any image-generation tool, delivers upload-ready folders behind your approval, then reads the numbers and improves the next plan through a read-only monitoring agent.

Works with Claude Code, the Claude desktop app, claude.ai skills and Codex. The skill's instructions are written in Arabic; it answers in the user's language.

---

## ما هي؟

«نَسَق» مهارة تصنع محتوى أي علامة في أي قطاع وتديره، على نسق واحد يتحسن بالأرقام:

```
ابحث في الجهاز واسأل ← استلهم ← جرّب أساليب ← خطّط ← أنتج وافحص ← سلّم للاعتماد ← قِس ← ثبّت ما نجح
```

استُخلصت من أسابيع محتوى حقيقية لعلامة تقنية وعلامة عقارية. كل ملاحظة رفض هناك صارت قاعدة، وكل رقم قُرئ بعد النشر صار قرارًا.

## ماذا تفعل؟

1. **تسأل أولًا.** في أول تشغيل تجري مقابلة من ثلاث جولات قصيرة (14 سؤالًا، ولكل سؤال اقتراح جاهز)، ثم تنشئ مشروع العلامة. وللمستعجل مسار من خمسة أسئلة.
2. **لا تفرض أسلوبًا.** تبحث عن هوية علامتك في ملفات جهازك (الشعار، والألوان، والخط، ودليل الهوية) وتحترمها. أما أسلوب المنشورات فتجرب منه اثنين أو ثلاثة في كل تشغيل، وأرقام جمهورك تختار. والأسلوب الذي ينجح يصير هوية محتواك.
3. **إلهام جديد في كل تشغيل.** تدرس ما ينتشر في منصات قطاعك ولماذا، في كل أسبوع لا في المرة الأولى فقط، وتكتب لكل منشور «بطاقة إلهام» تربطه بمرجع.
4. **تستأذن قبل توليد الصور.** تكتشف أدوات التوليد المتاحة عندك (Codex CLI، أو OpenRouter، أو أي أداة مسموح لها بها)، ثم تسألك: الأداة، والغرض، والسقف. وتبدأ بصورة تجريبية واحدة.
5. **تخطط لأسبوع أو شهر.** لكل فكرة موجز، ووسوم، ونص لكل منصة بصوتها.
6. **تصمم بالكود وتفحص آليًا.** شرائح HTML إلى PNG، مع فحص التباين وتصادم النص والهوامش، ثم ثلاثة نقّاد مستقلين.
7. **تسلّم ولا تنشر.** مجلد لكل منصة بترتيب الرفع ونص كل منشور. النشر لك بعد اعتمادك.
8. **تقيس وتحسّن.** سجل واحد لحالة كل منشور وأرقامه، ووكيل مراقب يقرأ الأرقام ويقترح ثلاثة قرارات على الأكثر كل أسبوع.

## الوكيل المراقب

`agents/content-growth-monitor.md` وكيل يتابع محتوى العلامة بعد النشر:

- يعرف أين يقف كل منشور: في الخطة، أو ينتظر الاعتماد، أو منشور، أو مقيس.
- يقرأ الأرقام بعد 24 ساعة و72 ساعة و7 أيام و28 يومًا، من المتصفح (قراءة فقط) أو ملف التصدير أو أرقام تلصقها.
- يقارن كل منشور بوسيط حسابك أنت، لا بحسابات غيرك، ويحكم بمقياس واحد يحدده هدفك.
- يفرّق بين «إشارة» و«نمط»، فلا يبني قاعدة على منشور واحد.
- يكتب تقرير الأسبوع، ويقترح: كرّر · عدّل · أوقف · اختبر.
- يحكم بين أساليب المحتوى: أيها يبقى، وأيها يخرج، ومتى يصير أسلوب «مرشحًا للتثبيت».

**حدوده:** لا ينشر، ولا يرد، ولا يعجب، ولا يتابع، ولا يحذف، ولا يطلب كلمة مرور، ولا يكتب رقمًا لم يقرأه. وكل تغيير في الإيقاع أو السلاسل أو نظام التصميم ينتظر اعتمادك.

## التثبيت

**Claude Code أو تطبيق Claude للكمبيوتر:**

```bash
git clone https://github.com/the-jundi/nasaq-content-studio ~/.claude/skills/nasaq-content-studio
```

**الوكيل المراقب** (مرة واحدة):

```bash
mkdir -p ~/.claude/agents && cp ~/.claude/skills/nasaq-content-studio/agents/content-growth-monitor.md ~/.claude/agents/
```

**Codex:** انسخ المجلد إلى مجلد المهارات عندك، ثم استدعِ `$nasaq-content-studio`.

**claude.ai (Skills):** نزّل المستودع ملفًا مضغوطًا، وسمِّ المجلد `nasaq-content-studio`، ثم ارفعه. التعليمات والمراجع والقوالب تعمل كاملة؛ والسكربتات تحتاج بيئة تنفّذ الكود.

**متطلبات السكربتات:** Python 3.9 أو أحدث. للتصميم والفحص:

```bash
pip install playwright pillow numpy
```

```bash
python -m playwright install chromium
```

`init_project.py` و`ledger.py` يعملان بلا أي مكتبة خارجية.

## جرّبها

1. **علامة جديدة:** «أبغى محتوى لمحمصتي على إنستقرام وإكس». المتوقع: تبحث عن ملفات هويتك وأدوات الصور، ثم تسألك قبل أن تقترح أي شيء.
2. **علامة سبق العمل عليها:** «كمّل محتوى [العلامة] للأسبوع القادم». المتوقع: ترث نظامها، وتبدأ من آخر تقرير أداء.
3. **القياس:** «كيف أداء محتوى [العلامة] هذا الأسبوع؟». المتوقع: الوكيل المراقب يقرأ ويكتب تقريرًا بثلاثة قرارات على الأكثر.
4. **فيه فخ:** «صمم منشورًا ليوم [يوم عالمي]». المتوقع: تعتذر وتقترح بديلًا.

وجرّب السجل والتقرير على البيانات التجريبية المرفقة:

```bash
python scripts/ledger.py report --ledger assets/ledger.example.json --now "2026-11-24 09:00"
```

## قواعد المهارة

المهارة تعكس طريقة عمل من بناها، ولها حد أدنى ثابت في كل علامة (التفاصيل في `SKILL.md` §3):

- لا أشخاص ولا وجوه في الصور المولّدة أو المركّبة، ولا موسيقى.
- لا محتوى مرتبطًا بالنساء أو الموسيقى أو ما يخالف الشريعة.
- العيدان فقط مناسبةً؛ لا محتوى للأيام العالمية والوطنية.
- الشعار الرسمي لا يُعاد رسمه، ولا رقم بلا مصدر.
- لا نشر ولا جدولة دون اعتمادك لكل منشور.

تضيف فوقها قيود علامتك في `brand.json`.

## الخصوصية والأمان

- المستودع لا يحوي مفاتيح ولا كلمات مرور ولا بيانات عملاء، والأمثلة كلها لعلامة تجريبية غير حقيقية.
- المهارة لا تطلب أسرار حساباتك. قراءة الأرقام تكون بدخولك أنت في المتصفح، أو بملف تصدّره.
- البحث في جهازك للقراءة فقط، واكتشاف أدوات الصور لا يستدعي أي خدمة ولا يقرأ قيمة أي مفتاح. ولا تُولَّد صورة قبل إذنك، ويُرسل للأداة وصف نصي فقط.
- كل ما تنتجه مسودة تنتظر اعتماد إنسان. المهارة لا تنشر ولا تجدول شيئًا بنفسها.
- لا تضع في مشروع علامتك بيانات خاصة لا تريد أن يقرأها الوكيل.
